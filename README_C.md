## 核心产物

### 编程辅导标准

| 维度   | 权重  | 说明          |
| ---- | --- | ----------- |
| 代码理解 | 20% | 对代码逻辑的解释清晰度 |
| 逻辑分析 | 20% | 分析代码问题的深度   |
| 调试技巧 | 20% | 提供具体的调试方法   |
| 最佳实践 | 20% | 推荐行业标准做法    |
| 架构设计 | 20% | 代码结构和可维护性   |

### 辅导反馈示例

```
【代码辅导报告】

总体评分：85/100

✅ 优点：
1. 代码逻辑清晰，变量命名规范
2. 基础功能实现完整
3. 注释适当，可读性好

⚠️ 需要改进：
1. 缺少异常处理
2. 部分函数可以进一步优化
3. 测试覆盖率有待提高

💡 具体建议：
- 添加 try-except 块处理边界情况
- 使用列表推导式简化循环
- 添加单元测试覆盖关键逻辑
```

## 学习成果

### 辅导原则

1. **解释细致**：逐行分析，确保理解每一行代码
2. **追踪过程**：记录学习进度，建立个人编程档案
3. **具体建议**：每条反馈都要有可执行的方案
4. **正向引导**：在指出问题的同时，肯定进步
