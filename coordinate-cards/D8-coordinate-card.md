## 流程节点

### 节点 1：用户输入

| 要素 | 说明 |
|------|------|
| 输入内容 | 代码片段、问题描述、学习目标 |
| 格式要求 | 支持 Python、JavaScript、Java 等多种语言 |
| 附加信息 | 学习阶段、知识背景、具体需求 |

### 节点 2：代码分析

| 要素 | 说明 |
|------|------|
| 分析维度 | 代码理解、逻辑分析、调试技巧、最佳实践、架构设计 |
| 分析深度 | 基础、详细、深入 |
| 输出结果 | 代码评估报告 |

### 节点 3：技能调用

| 技能 | 调用条件 | 输出 |
|------|----------|------|
| code_reviewer | 代码质量评估 | 评分报告 |
| bug_finder | 问题检测 | Bug 列表 |
| best_practice | 规范检查 | 优化建议 |
| architecture_guide | 架构分析 | 重构建议 |

### 节点 4：生成报告

| 报告类型 | 内容 |
|----------|------|
| 综合报告 | 总体评分、各维度分析 |
| 详细报告 | 具体问题、改进建议 |
| 学习报告 | 学习路径、练习建议 |

### 节点 5：反馈学习

| 反馈类型 | 内容 |
|----------|------|
| 即时反馈 | 代码修改建议 |
| 学习追踪 | 进度记录、能力评估 |
| 进阶建议 | 学习资源推荐 |

## 工作流参数

### 输入参数

| 参数 | 类型 | 说明 | 默认值 |
|------|------|------|--------|
| code | string | 用户代码 | 必需 |
| language | string | 编程语言 | python |
| depth | string | 分析深度 | detailed |
| learning_stage | string | 学习阶段 | beginner |

### 输出参数

| 参数 | 类型 | 说明 |
|------|------|------|
| score | int | 总体评分 | 0-100 |
| dimensions | object | 各维度得分 | 见下表 |
| strengths | array | 优点列表 | 字符串数组 |
| improvements | array | 改进项列表 | 字符串数组 |
| suggestions | array | 具体建议 | 字符串数组 |
| optimized_code | string | 优化后代码 | 字符串 |

### 维度评分

| 维度 | 权重 | 评估内容 |
|------|------|----------|
| code_understanding | 20% | 代码逻辑、变量命名、注释 |
| logic_analysis | 20% | 算法设计、复杂度、效率 |
| debugging_techniques | 20% | Bug 检测、异常处理、边界情况 |
| best_practices | 20% | 代码规范、设计模式、可读性 |
| architecture_design | 20% | 模块化、可扩展性、可维护性 |

## 决策点

### 决策点 1：分析深度选择

```
用户输入代码 → 判断代码复杂度
    │
    ├─ 简单代码 → 基础分析 (basic)
    │
    ├─ 中等代码 → 详细分析 (detailed)
    │
    └─ 复杂代码 → 深入分析 (deep)
```

### 决策点 2：技能调用策略

```
分析代码类型 → 选择调用技能
    │
    ├─ 新手代码 → code_reviewer + bug_finder
    │
    ├─ 进阶代码 → code_reviewer + best_practice
    │
    └─ 项目代码 → architecture_guide + best_practice
```

### 决策点 3：反馈方式选择

```
学习阶段判断 → 选择反馈方式
    │
    ├─ 初学者 → 详细解释 + 代码示例
    │
    ├─ 进阶者 → 要点提示 + 参考链接
    │
    └─ 高级者 → 架构建议 + 优化方向
```

## 异常处理

### 异常类型

| 异常 | 处理方式 | 用户提示 |
|------|----------|----------|
| 代码为空 | 返回错误信息 | "请输入代码内容" |
| 语言不支持 | 返回支持列表 | "暂不支持该语言" |
| API 调用失败 | 重试或降级 | "服务暂时不可用" |
| 分析超时 | 返回部分结果 | "分析时间较长" |

### 容错机制

1. **重试机制**：API 调用失败时自动重试 3 次
2. **降级策略**：服务不可用时提供基础分析
3. **缓存机制**：相同代码分析结果缓存 1 小时
4. **日志记录**：记录所有异常供排查
